# 后置能力与测试

下面这些能力规格要写清，实现排在主循环能稳定写书之后。主循环的阶段见 [实现顺序](08-roadmap.md)。

## 导入

导入不是正则切章再让模型一次吐出整本书，也不是一个自由运行的导入代理。它是一条分阶段编译，在独立工作区里验证，通过后才发布到正式书籍目录。

```text
外部文本
  → 确定性读取与换行归一
  → 模型识别章节、卷和附属文本的边界
  → 代码核对全文覆盖，不丢行
  → 用户确认切分（可显式授权自动接受）
  → 模型按连续章节批次提取每章事实
  → 模型聚合成前提、角色、世界规则、大纲和指南针
  → 代码组装并校验设定
  → 幂等发布章节和设定
  → 默认暂停；只有显式继续才进入正常写作门禁
```

模型负责开放语义。代码负责坐标、覆盖、类型、哈希、顺序和幂等。每个阶段的输入指纹绑定该阶段工件，中断后从下一个未完成阶段继续，不重做已发布的文件。

切分失败时保存模型的原始响应，便于看是格式错还是语义错。发布前的文件不写进正式的 `chapters/` 和 `meta/progress.json`。

角色上可以单独指定切分、逐章分析、全书合成三个模型，与写作者分开。

## 导出

只读。把已提交章节导出为 TXT 或 EPUB 3。不改进度，不触发路由。

## 诊断

诊断跨读工件、会话、日志和检查点，做两件事：

- 创作质量：规则产生发现，给人读的报告。
- 运行排错：导出时去掉正文，保留行为骨架和循环聚合。

诊断可以指出问题，不可以改文件、续跑或改流程。

## 离线评测

`eval` 子命令不进入写作循环。它用同一套提示词组装函数比较文风或协议的两个版本，并用 `decisions.jsonl` 重放裁定：同一事实必须得到校验通过的同类决定，或明确记录模型输出变了。评测不写正式书目录。

## 测试分层

用 `pytest`。控制面先有测试再有实现。模型调用在单测里用假模型，返回预先写好的工具参数或裁定 JSON。

| 层 | 测什么 | 完成时的样子 |
|---|---|---|
| 领域 | 阶段和流程的合法迁移、非法迁移、推进模式未知值 | 表驱动，含空值和完本重开 |
| 存储 | 原子替换不损坏旧文件；检查点相同摘要不追加；`Init` 保留 `pending_steer` 和放行模式 | 临时目录，不碰真实书 |
| 路由 | `Route` 无 IO。决策顺序的每一条分支，以及互斥时高优先级胜出 | 穷举或生成组合。至少覆盖文档里的 10 条优先级和弧末缺口顺序 |
| 工具 | 缺前置拒绝；`edit_chapter` 拒绝不在队列中的章；提交 Saga 在每个阶段杀掉后续跑，终稿字节不变 | 假存储或临时书目录 |
| 裁定 | 非法规划师、完本期直接派单、重开越界、`reroute` 缺派单都被机械校验拒绝 | 不调用真实模型也能测校验；另有一条假模型返回合法 JSON |
| 引擎 | 假模型走完：规划 → 补齐 → 写一章 → 弧末审阅与摘要 → 展开 → 完本。另测失败裁定、僵局第 5 次暂停、逐章许可只消费一次、边界暂停立即停 | 真实工具函数、假模型 |
| 恢复 | 提交各阶段留下 `pending_commit` 再启动，不采用新的模型参数 | 草稿被改写后仍用冻结快照 |
| 文风组装 | `{{VOICE}}` 替换只有一个入口；本书覆盖、全局覆盖、内置默认的顺序固定 | 字符串快照 |

路由测试要能证明 `Route` 不进口存储模块。可以用依赖检查或在测试里断言状态对象之外没有文件路径参数。

引擎结束函数里不允许出现再次启动引擎的调用。这条可以做成源码扫描测试，避免以后补上自动续跑。

## 稳定性场景（实现后期）

这些不阻塞前几个阶段，但是头一次长跑前要有记录：

- 一次跑完短篇书，阶段变为 `complete`。允许提供方切换和重试。禁止自动续跑。
- 任意步骤杀掉进程再恢复：已落盘章不重写，检查点不出现重复的同摘要步骤。
- 运行中干预：裁定回显，改队列的动作在边界生效。停机时干预按意图拉起。崩溃后 `pending_steer` 会重放。
- 间歇 503：备用提供方接上，写作者无感。

## 和 Go 版对齐的验收

抽一本 Go 版已经写过若干章的书目录，用 Python 只读打开：进度、大纲、终稿、检查点能解析。再在副本上提交一章，Go 版能读这章的 `chapters/NN.md`、`meta/progress.json` 和新增的检查点行。字段名不一致就算未完成。
